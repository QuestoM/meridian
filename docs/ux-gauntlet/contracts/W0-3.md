# W0-3 advertiser identity and spot-ledger contract

Published and frozen on delivery under the wave-zero contract rule. W0-3 owns
advertiser identity and the shared read-only money join. Later pieces consume
this API; they do not re-price spots, regroup the export independently, or
mutate this module.

## Frozen shared file

`kairos_api/spot_ledger.py` is the sole grouped reader over the daily spot
pricing pipeline. It composes `kairos_api.exporters._load_daily_pricing`, the
same pricing run used by the spot export and agency totals. It does not contain
a second pricing formula.

## Public data shapes

```python
@dataclass(frozen=True)
class AdvertiserMoney:
    advertiser: str
    gross: float = 0.0
    net: float = 0.0
    spots: int = 0
    dropped_by_rule: int = 0
    dropped_by_frequency: int = 0

    def as_dict(self) -> dict[str, Any]


@dataclass(frozen=True)
class LedgerRead:
    available: bool = False
    reason: str = ""
    basis: Optional[str] = None
    gross: Optional[float] = None
    net: Optional[float] = None
    spots: Optional[int] = None
    dropped_by_rule: Optional[int] = None
    dropped_by_frequency: Optional[int] = None
    by_advertiser: dict[str, AdvertiserMoney] = field(default_factory=dict)

    def for_advertiser(self, advertiser: str) -> Optional[AdvertiserMoney]
    def totals_dict(self) -> dict[str, Any]
```

`AdvertiserMoney.as_dict()` rounds `gross` and `net` to two decimals and
returns all six fields. `LedgerRead.totals_dict()` returns every top-level field
except `by_advertiser`.

## Public functions

```python
def read_ledger() -> LedgerRead
def group_result(result: Any, *, basis: Optional[str] = None) -> LedgerRead
```

`read_ledger()` prices the newest daily file once through the shared exporter
composition and then delegates to `group_result`. `group_result` groups exact
advertiser strings from the daily input across priced, rule-dropped and
frequency-dropped spots. Identity resolution remains the caller's job; this
layer must not merge aliases or invent advertiser records.

## Availability and money semantics

- When no daily file exists, `available` is false, `by_advertiser` is empty,
  every numeric total is `None`, and `reason` explains the absence.
- When the pricing pipeline raises, the same unavailable shape is returned
  with a pipeline-failure reason. There is no fallback estimate.
- On success, `gross` and `net` come from the pricing result totals; per
  advertiser gross/net are sums of the result's priced spots. `spots` counts
  priced spots. Both dropped counts remain visible even when an advertiser has
  no priced spot.
- `basis` is the newest daily filename when it can be named, otherwise `None`.
  Failure to name the file does not turn real ledger money into unavailable
  money.
