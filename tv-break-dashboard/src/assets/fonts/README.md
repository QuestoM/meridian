# Kairos local fonts

`noto-sans-hebrew-hebrew-wght-normal.woff2` is the Hebrew-only, variable-weight
WOFF2 from `@fontsource-variable/noto-sans-hebrew` 5.3.0 (font metadata version
v50). The source package identifies the upstream as
<https://github.com/google/fonts> and credits the Noto Project authors at
<https://github.com/notofonts/hebrew>.

The font is licensed under SIL Open Font License 1.1; the copied license is in
`Noto-Sans-Hebrew-OFL-1.1.txt`. SHA-256:
`8dd0a0bc744eca2c6d5d618bf002f8ef98b2948b31020e3cb64fe3587c9abb74`.

Only the Hebrew subset is bundled. Latin letters and numerals deliberately use
the existing local IBM Plex Sans assets, avoiding a second Latin text voice in
mixed Hebrew/English operational data.
